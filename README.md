# Food Ordering App 🍽️🚀

A **scalable and modern Food Ordering Web Application** built using **React** and **Redux Toolkit**, integrated with **live Swiggy API** to fetch real-time restaurant and menu data. The application is designed with a **mobile-first approach**, focusing on performance, clean architecture, and real-world usability.

---

## ✨ Key Features
- 🔴 **Live Swiggy API Integration** for real restaurant & menu data
- 🔍 **Search Functionality** to find restaurants quickly
- ⭐ **Top-Rated Restaurant Filter**
- 🛒 **Cart Management** using Redux Toolkit
- ➕ Add / ➖ Remove food items from cart
- 🧭 **Client-side Routing** with React Router DOM
- 📱 **Mobile-First Responsive Design**
- 🎨 **Tailwind CSS** for fast and consistent UI styling
- ♻️ Reusable & modular React components
- ⚡ Optimized performance and clean folder structure

---

## 🛠️ Tech Stack
- **React**
- **Redux Toolkit**
- **React Router DOM**
- **Tailwind CSS**
- **JavaScript (ES6+)**
- **HTML5 & CSS3**
- **Live Swiggy API**
